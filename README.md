## Main features
Pick one of these as the base tweak with the **variant** dropdown when you run the workflow.

- **[YouPro](https://t.me/alibusut)** (`youpro`) - Basic Youtube Premium features; Download Videos, No ads, Background Playback.
- **[YoutubePlus/YTLite](https://github.com/dayanch96/YTLite)** (`ytlite`) - A flexible enhancer for YouTube on iOS, featuring over hundred customizable options.
- **[YTKillerPlus](https://repo.ikghd.me/depictions/?p=me.ikghd.ytkplus)** (`ytkplus`) - Alternative Youtube tweak with more customized options.
- **[YouMod](https://github.com/Tonwalter888/YouMod)** (`youmod`) - a free alternative youtube tweak with customized options.
- **[YTKACE](https://github.com/itzzace/ytkace)** (`ytkace`) - A new free and open-source YouTube enhancer for iOS with downloads, SponsorBlock, DeArrow, player controls, and interface customization.
- **Your own `.deb`** (`custom`) - Use any tweak you like (e.g. YTLite/YTKACE/YouTubeX) by pasting a link to its `.deb`.
- **No base tweak** (`none`) - Only the extra tweaks below, nothing else.
- **[YTMusicUltimate](https://github.com/mrdrvt99/YTMusicUltimate)** - Background playback, ad removal, Downloads and other small improvements.

>
> ```

> ⚠️ If you already have one of these tweaks installed from a direct IPA or previous sideload, **do not tap Update**. Delete the installed tweak first, then install a fresh version from the source.

## How to build a YoutubePINK IPA using Github Actions
> [!NOTE]
> Make sure to provide a **direct download link** to the file, not a link to a webpage. Otherwise, the process will fail.

<details>
<summary>How to build a YoutubePINK IPA</summary>

1. Fork [ikyih/YoutubePINK](https://github.com/ikyih/YoutubePINK). If you already have a fork, click on **Sync fork**, and if your branch is out-of-date, click on **Update branch**.
2. Navigate to **Actions** in your forked repository and select **Build IPA**.
3. Click the **Run workflow** button located on the right side.
4. Get a decrypted `.ipa` file (I cannot provide this due to legal reasons.), then upload it to a file provider (e.g., buzzheavier.com, filemail.com, catbox.moe, or Dropbox are recommended). Paste the URL of the decrypted IPA file in the provided field.
5. Choose the base tweak from the **variant** dropdown (`youpro`, `ytlite`, `ytkplus`, `youmod`, `ytkace`, or `none`).
6. Integrate the tweaks from the toggles, and if you want you can also change the BundleID and Display Name if desired.
7. Make sure all inputs are correct, then click **Run workflow** to start the process.
8. Wait for the build to finish. You can download the IPA from the **Releases** section of your forked repo (it's created as a draft).  
   (If you can't find the Releases section, go to your forked repo and add `/releases` to the URL, i.e., `github.com/yourusername/YoutubePINK/releases`.)

</details>

<details>
<summary>How to build a Pink IPA (With your own .deb file)</summary>

1. Fork [ikyih/YoutubePINK](https://github.com/ikyih/YoutubePINK). If you already have a fork, click on **Sync fork**, and if your branch is out-of-date, click on **Update branch**.
2. Navigate to **Actions** in your forked repository and select **Build IPA**.
3. Click the **Run workflow** button located on the right side.
4. Get a decrypted `.ipa` file (I cannot provide this due to legal reasons.), then upload it to a file provider (e.g., buzzheavier.com, filemail.com, catbox.moe, or Dropbox is recommended). Paste the URL of the decrypted IPA file in the provided field.
5. Set the **variant** dropdown to `custom`.
6. Get your Custom `.deb` file, then upload it to a file provider (e.g., buzzheavier.com, catbox.moe, or Dropbox are recommended). Paste the URL of the deb file in the **deb_url** field.
7. Integrate the tweaks from the toggles, and if you want you can also change the BundleID and Display Name if desired.
8. Make sure all inputs are correct, then click **Run workflow** to start the process.
9. Wait for the build to finish. You can download the IPA from the **Releases** section of your forked repo.  
   (If you can't find the Releases section, go to your forked repo and add `/releases` to the URL, i.e., `github.com/yourusername/YoutubePINK/releases`.)

</details>

> [!CAUTION]
> Every tweak above can be switched on for any variant. Turning on a lot of them may crash your IPA. Test every tweak.

> [!IMPORTANT]
> If you modified any workflow files, delete the existing caches in the Actions tab before running a new build.
